# 3D ASSET PACK

В этой версии 3D-модели **уже лежат внутри проекта** и загружаются локально из `assets/models/`.

## Что добавлено

```text
assets/
└── models/
    ├── barrel_01.glb
    ├── crate_01.glb
    ├── rock_01.glb
    ├── tree_01.glb
    ├── toolbox_01.glb
    ├── crowbar_01.glb
    └── pistol_fictional_01.glb
```

### Где они используются

- `tree_01.glb` — деревья по карте.
- `rock_01.glb` — камни/ресурсные узлы.
- `barrel_01.glb` — промышленные бочки.
- `crate_01.glb` — ящики.
- `toolbox_01.glb` — инструментальные ящики.
- `pistol_fictional_01.glb` — оружие от первого лица.
- `crowbar_01.glb` — модель инструмента, подготовлена для будущего хотбара/лут-контейнеров.

## Формат

Все модели — **GLB**, поэтому текстуры и геометрия хранятся внутри одного файла. Это удобно для GitHub Pages: не нужны отдельные `.bin` и папки с текстурами.

Модели в этой сборке — оригинальные лёгкие low-poly ассеты, созданные специально для прототипа. Они не являются моделями из Rust и не копируют их проприетарные ассеты.

## Производительность

Я специально сделал модели компактными, чтобы проект оставался пригодным для запуска в браузере на iPad. Высокополигональные модели из фотограмметрических библиотек могут сильно снизить FPS и увеличить размер репозитория.

## Внешние бесплатные ассеты для следующего этапа

Для последующего повышения качества можно заменить отдельные GLB на CC0-модели из **Poly Haven**. Poly Haven указывает, что их 3D-модели распространяются под CC0; при использовании их live API сам сайт просит явно указывать источник Poly Haven. Примеры подходящих ассетов:

- Barrel_01 — металлическая бочка, 3K tris: https://polyhaven.com/a/Barrel_01
- Barrel Stove — ржавая бочка-печь, 11K tris: https://polyhaven.com/a/barrel_stove
- Crowbar 01 — лом, 2K tris: https://polyhaven.com/a/crowbar_01
- Wooden Barrels 01 — набор деревянных бочек, 33K tris: https://polyhaven.com/a/wooden_barrels_01
- Poly Haven Models — каталог: https://polyhaven.com/models
- Poly Haven License — условия CC0: https://polyhaven.com/license

## Важно

Не добавляйте в репозиторий реальные ассеты Rust/Oxide, если у вас нет соответствующих прав. Для этой игры используйте свои модели или ассеты с подходящей лицензией.
