# Wasteland — Rust-like browser survival prototype

Готовый браузерный 3D survival-прототип для GitHub Pages. В этой сборке добавлен локальный GLB-пак: деревья, камни, бочки, ящики, toolbox и отдельная модель вымышленного пистолета.

## Запуск через GitHub Pages

1. Создайте новый публичный GitHub-репозиторий.
2. Загрузите **все файлы и папки** из этого архива.
3. Откройте `Settings → Pages`.
4. В `Build and deployment` выберите `Deploy from a branch`.
5. Выберите `main` и `/ (root)`.
6. Сохраните и откройте выданный GitHub Pages URL.

## Что работает

- 3D first-person мир на Three.js.
- Процедурный рельеф и туман.
- Локальные GLB-модели вместо одних примитивов.
- Деревья и камни как ресурсные узлы.
- Промышленная зона с пропами.
- Пистолет от первого лица.
- Инвентарь и крафт.
- Строительство простой стены.
- WASD + Space на ПК.
- Виртуальный джойстик и кнопки на iPad/телефоне.
- Хотбар 1–8.

## Ограничения

Это всё ещё **single-player прототип**, а не полноценный Rust-клон: нет настоящего сервера, синхронизации игроков, PvP-сети, авторизации, persistence-базы, античита и полного набора механик Rust.

## 3D-модели

Модели в `assets/models/` — оригинальные лёгкие low-poly ассеты, подготовленные специально для этого прототипа. Они сделаны так, чтобы не перегружать iPad и GitHub Pages.

Для будущего улучшения визуала можно постепенно заменять их на CC0-модели Poly Haven или другие модели с подходящей лицензией. См. `ASSET_NOTES.md`.

## Важный момент для GitHub Pages

`index.html` подключает Three.js и `GLTFLoader` через jsDelivr, а **GLB-модели загружаются из самого GitHub-репозитория**. Поэтому после публикации нужно сохранить структуру папок без переименования `assets/models/`.
